# anchor-mc

**Paper 서버용 엑스레이 탐지 플러그인(섀도 모드).** 플레이어마다 가짜 다이아 광석 미끼를 보여 주고, 미끼와 "아무것도 안 보여 주는 대조 자리(위약)"에 대한 반응을 비교해서
엑스레이 사용 여부를 통계적으로 확정합니다. **처벌하지 않습니다.** 확정되면 서버 콘솔 로그와 관리자 알림만 나갑니다.

- 정직한 플레이어는 미끼를 볼 수 없으니 미끼와 위약에 같은 정도로 반응합니다. 엑스레이는 미끼에 더 반응합니다.
- 판정은 확률 계산이라, 정직한 플레이어를 잘못 확정할 확률의 상한이 수학적으로 정해져 있습니다(기본 10⁻⁹).
- 서버 월드는 건드리지 않습니다. 미끼는 해당 플레이어에게 가는 청크 패킷에만 들어갑니다.

> 1.0.0은 **섀도 모드 전용**입니다. 자동 킥·밴 코드가 없습니다. 확정 결과로 무엇을 할지는 운영자가 직접 정합니다.

## 필요한 것

| 항목 | 요구 |
| --- | --- |
| 서버 | **Paper 26.2** (`api-version: 26.2`) |
| Java | **25** (Paper 26.2가 요구) |
| 필수 플러그인 | **[PacketEvents](https://github.com/retrooper/packetevents) 2.14.0 이상**(Spigot/Paper용 플러그인 jar를 `plugins/`에 설치) |
| 네트워크 | 첫 시작 때 Paper가 SQLite 라이브러리(`org.xerial:sqlite-jdbc`)를 내려받는다(인터넷 필요, 이후엔 캐시) |

## 설치

1. `plugins/`에 **PacketEvents**와 **anchor-mc-1.0.0.jar**를 넣습니다.
2. 서버를 켭니다. 처음 켜면 `plugins/AnchorMC/config.yml`이 만들어지고, 콘솔에 "secret-seed가 비어 있어 새로 만들어 저장했다" 경고가 **한 번** 뜹니다(정상, 값은 출력되지 않음). 이 시드는 서버마다 무작위로 생성됩니다.
3. 콘솔에 `anchor-mc 켜짐(섀도 모드 …)`이 보이면 끝입니다. 서바이벌로 지하에 내려가 `/anchor stats`에서 "청크 패킷에 미끼 삽입"이 늘어나는지 확인하세요.
4. 권한: `anchor.admin`(명령 사용, 기본 op), `anchor.alert`(확정 알림 수신, 기본 op). 권한 플러그인으로 필요한 사람에게만 주세요.

**업데이트할 때**: 새 버전을 넣어도 기존 `config.yml`은 덮어쓰지 않습니다. 서버를 켤 때 예전 형식이거나 키가 빠졌거나 `confirm-rule`이 기본값과 다르면 콘솔에 경고하고, 지금 적용되는 확정 조건을 한 줄로 알려 줍니다. 경고를 보고 직접 고치세요.
**`secret-seed`는 백업하고 외부에 알리지 마세요.** 값을 바꾸면 모든 미끼 자리가 바뀌고, 유출되면 미끼 위치를 예측할 수 있습니다.

## 명령어

모두 `anchor.admin` 권한이 필요합니다.

| 명령 | 설명 |
| --- | --- |
| `/anchor status <플레이어>` | 그 플레이어의 미끼·위약 관측, 먼저 반응 증거(log10E), 확정 여부. 혼합·쌍(한쪽만) 값은 참고용 |
| `/anchor stats` | 전체 위약 반응률(p₀), 확정 계정 수, 청크 패킷에 미끼를 넣은 횟수, 회수 사유별 통계 |
| `/anchor debug <플레이어>` | 그 플레이어에게 계획된 미끼·위약 좌표와 상태(**좌표가 그대로 나오니 관리자 전용**) |
| `/anchor reset <플레이어>` | 그 플레이어의 기록(SQLite 포함)·e-value·반응 기록을 지운다. **확인 없이 즉시 실행**, 콘솔에 로그를 남긴다 |
| `/anchor simtest <플레이어> xray <개수>` | 시험용: 그 플레이어를 미끼로 파 들어가게 한다 |
| `/anchor simtest <플레이어> honest <블록수>` | 시험용: 미끼·위약 정보 없이 직진 채굴 |
| `/anchor simtest <플레이어> honest-branch <본갱도 블록수>` | 시험용: 본갱도 + 3블록 간격 곁가지, 보이는 진짜 광석은 캐러 감. 경로 둘레의 물·용암은 돌로 막는다 |
| `/anchor reload` | `config.yml`을 다시 읽는다(`secret-seed` 변경은 재시작 필요) |

`simtest`는 서바이벌 플레이어에게만 동작하고 게임모드는 바꾸지 않습니다. 시험 계정의 기록은 `/anchor reset`으로 지우세요.

## 설정(`plugins/AnchorMC/config.yml`)

기본값으로 대부분 충분합니다. 주로 보는 항목만 적습니다(각 줄의 자세한 주석은 파일 안에 있습니다).

| 키 | 기본 | 설명 |
| --- | --- | --- |
| `shadow-mode` | `true` | 처벌 없이 기록·알림만. 1.0.0에는 처벌 동작이 없어 `false`여도 똑같이 동작합니다 |
| `confirm-rule` | `PAIRED` | 확정 규칙. **`PAIRED`(권장)**: "먼저 반응한 쪽" 정확 검정만 사용. `MIXTURE`/`BOTH`: 혼합 e-value 사용(근사라 정확한 오탐 상한이 없음) |
| `alpha` | `1.0e-9` | 확정 문턱 E ≥ 1/alpha. 정직한 플레이어를 확정할 확률의 이론 상한 |
| `window-seconds` | `240` | 한 자리의 판정 시간 창. 반응은 창이 끝난 뒤 증거에 반영됩니다(그래서 `status`에는 최대 이만큼 늦게 보임) |
| `reaction-radius` | `3.0` | 이 거리 안에 들어오면(또는 이 안의 블록을 캐면) 반응 |
| `sites.pairs-per-chunk` | `2.0` | 청크당 (미끼, 위약) 쌍 수의 기댓값. 올리면 검출이 빨라지고 패킷 비용이 늘어납니다 |
| `sites.y-min` / `y-max` | `-64` / `16` | 미끼를 놓는 높이 범위 |
| `secret-seed` | `""` | 비워 두면 첫 실행 때 무작위로 생성해 저장 |
| `storage.file` | `anchor.db` | 증거를 저장하는 SQLite 파일(플러그인 폴더 안) |
| `debug.allow-spectator` | `false` | 테스트용. 켜 둔 채 운영하지 마세요(켜면 콘솔에 큰 경고) |

## 동작 원리(짧게)

1. 서버가 플레이어에게 청크를 보낼 때, 그 청크 안에서 **(미끼, 위약) 두 자리**를 (플레이어, 청크, 서버 비밀 시드)로 결정적으로 정합니다. 자리는 진짜 다이아 광맥의 모양·크기·높이를 흉내 내고, **여섯 면이 전부 막힌 돌 속**에만 둡니다.
2. 동전 던지기로 한 자리는 **미끼**(그 플레이어의 청크 패킷 안 블록을 가짜 다이아로 바꿈), 다른 자리는 **위약**(아무것도 안 바꿈)이 됩니다. 서버 월드는 그대로입니다.
3. 플레이어(또는 캐는 블록)가 자리 반경 안에 들어오면 **반응**입니다. 정직한 플레이어는 둘에 똑같이 반응하고, 엑스레이는 미끼에 먼저 반응합니다.
4. 반응이 나온 쌍마다 **먼저 반응한 쪽이 미끼였나 위약이었나**를 셉니다. 귀무(엑스레이 아님)에서는 동전 때문에 정확히 1/2이라, 이 비교만으로 정확한 e-value 검정이 됩니다(p₀ 추정 불필요).
5. 누적 증거가 문턱(기본 10⁹)을 넘으면 **확정**: 콘솔 경고 + `anchor.alert` 권한자 알림. 그 외의 일은 하지 않습니다.
6. 미끼 주변 블록이 바뀌어 노출될 위험이 생기면(블록 파괴·폭발·유체·피스톤 등) 미끼는 그 전에 진짜 블록으로 되돌리고 증거에서 뺍니다.

저장하는 데이터: 계정별 UUID, 마지막 이름, 관측 횟수, e-value 기록, 확정 시각(SQLite `accounts` 표). 좌표·개별 이벤트·시드는 저장하지 않습니다.

## 검증 상태와 한계

- 서버 없는 시뮬레이터에서 정직 1500계정(동굴 탐색 + 브랜치 마이닝) 확정 **0건**, 엑스레이는 미끼를 100% 믿는 유형 100% / 50% 믿는 유형 91% / 20% 믿는 유형 2%를 확정했습니다(확정까지 채굴 약 29분 / 75분 / 110분). 시뮬레이터는 모델이지 사람 데이터가 아닙니다.
- 실서버 시험(`simtest`): 엑스레이 모드는 확정, 직진·가지치기 정직 모드는 미확정입니다(수치는 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)). 시험당 한 번이라 오탐률·검출력의 실서버 추정은 아닙니다.
- 미끼를 가까이서 갑자기 나타났다고 걸러 내는 **검증형 엑스레이** 등 알려진 한계는 개발 기록에 있습니다.
- 메시지와 문서는 한국어입니다.
